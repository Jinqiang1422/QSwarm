## 三、各工作包细节

### WP3.7 感知消息契约（单源事实，双端镜像）

- `mavlink/swarm_perception.xml`：原生消息契约（SWARM_PERCEPTION_HEARTBEAT / SWARM_TARGET_TRACK / SWARM_PLAN_META + 类别/来源枚举），供后续 mavgen 接入
- 当前传输：MAVLink TUNNEL(#385) 语义承载，沙箱/联调用 UDP 直传同一字节流
  - 帧格式 `[payload_type:2B][seq:1B][JSON 分片≤126B]`；42000 单帧 / 42001 中间 / 42002 尾
  - **航迹紧凑线格式**：位置式数组 `[id,cat,lat×1e7,lon×1e7,alt_dm,ve_cm,vn_cm,conf×1000,sensor,source,t]`（全字段 JSON 超 128B，紧凑化后单帧承载）
- 双端实现严格同构：Python `swarm_msgs.py` ↔ C++ `SwarmTunnelProtocol.h`（头文件 QtCore-only，Bridge 与单测共用）

### WP3.2 检测跟踪服务（services/perception/）

- **检测器层**：`DetectorBase` 统一接口；`SimulatedDetector`（真值目标 WGS84 航路点 → 针孔投影 → 加噪/漏检/虚警，无 GPU 验证全链路）；`OnnxDetector`（ultralytics 真实部署入口，接口一致可热替换）
- **跟踪器**：ENU 恒速 Kalman（4 状态，马氏距离门限 χ²=9.21）+ 匈牙利关联（scipy，缺省贪心降级）；tentative(≥3 命中转 confirmed)→coasting(≤5 帧保留)→删除
- **地理解算**：`pixel_to_geo`（针孔+平地假设，朝天/超 3km 拒绝），与 C++ `SwarmVideoHub::pixelToGeo` 同公式，跨语言偏差 <1e-3 m
- **运行形态**：`--out udp://host:15600 --realtime`（部署）/ `--out file://tracks.jsonl`（CI）/ `--dry-run`

### WP3.3 多源航迹融合（SwarmTrackFusion，QtCore-only）

- 最近邻关联（门限 25m，**速度外推补偿上报间隔**上限 2s 防 coasting 外推发散）
- 置信度加权融合：位置新息增益、速度阻尼 0.4、多源置信度递推提升（0.8→0.9+）
- 生命周期：tentative(命中<2) / confirmed / coasting(>3s 未更新) / 删除(>10s)
- 场景 06 验证：双传感器接力（cam1↔cam2 交接）同目标合一，远距目标分裂

### WP3.4 共同态势图 COP

- **SwarmCOPModel**（QAbstractListModel）：统一目标清单（fusedId/类别/坐标/速度/置信度/状态/年龄，11 角色）、威胁区多边形（fences.json exclude 自动载入）、覆盖热力格网（0.0005°≈55m，权重 1~10，限频刷新，上限 500 格防膨胀）
- **SwarmSituationLayer.qml**：MapItemView 三层叠加——目标标记（类别色点+置信度环+编号/速度标签，coasting 变灰）、威胁区红多边形、热力琥珀格网；集成补丁见《集成补丁说明.md》补丁 5
- 刷新：融合节拍 2Hz ≥ 指标 1Hz

### WP3.5 态势摘要与问答（防幻觉核心）

- **SwarmSituationDigest**：结构化摘要每块带 source（telemetry/perception/inferred），`oneLiner()` 单行态势随面板状态栏 2Hz 刷新
- **三通道**：
  1. 每轮对话上下文自动携带 situation 块（航迹+告警）——所有问答天然有依据
  2. 周期摘要：`_sendSituationSummary`（面板开关+间隔 10~3600s）→ LLM 生成 ≤3 句简报
  3. 态势问答：`askSituation()` 携带完整摘要提问
- **来源标注**：系统提示规则 11——事实性陈述必须带 [遥测]/[感知]/[推测] 角标，摘要没有的数字禁止编造；评测集 J_no_fabrication 4 条专测护栏；评测指标新增 `source_label_rate`

### WP3.6 异常事件检测告警

- **平台异常**：低电 critical<20%/warning<30%、离线跳变、机体越出围栏（include 外/exclude 内）
- **目标异常**：聚集（≥3 目标 <50m）、禁飞区闯入、速度突变（|Δv|>8m/s）/超速（>25m/s）
- **去抖**：同 rule+对象 30s 冷却，critical 不过冷却；告警留痕 20 条
- **联动**：告警→面板分级色列表+应用消息条+审计 safety/alert；critical → `requestAdvice()` 异步 LLM 处置建议（限已提供工具）

### WP3.1 视频汇聚（SwarmVideoHub，QtCore-only）

- 通道注册表（sensorId↔流地址↔机体）、统一时间戳（首帧标定偏移，流内时基→本地单调钟）
- `pixelToGeo`/`footprint` 与 Python 端同公式镜像；GStreamer 解码复用 QGC VideoReceiver（本模块不重造解码，务实裁剪：多路 720p 实测在部署环境进行）
