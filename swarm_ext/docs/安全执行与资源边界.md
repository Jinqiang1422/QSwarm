# 集群执行安全与资源边界

本文说明集群功能的权限、航线校验、任务结果与感知容量行为。标准 QGC 的人工飞行和任务编辑工作流仍可使用。

## 权限变化

L2 中的集群自动动作需要人工确认。L3 中只有白名单允许的动作可以自动受理。
确认时绑定的成员不会随界面选择变化而改变。

从 L3 降为 L2，或收紧 L3 白名单时，已经人工确认的任务仍可按确认范围继续；
没有人工确认、且不再符合新策略的后续动作会被取消。切到 L1 后自动任务不能继续下发动作，自动编队引导停止。
操作员的人工直控保留。已经送到飞控的请求可能仍有协议重试，撤销不会自动反向执行已经生效的飞行指令。

交错下发以及固件内部后续切模式、解锁和启动步骤都会重新检查当前许可、控制租约、成员身份和相关约束。
放宽策略或恢复配置不会自动恢复已取消的执行。阶段已经部分执行时，应中止后重新启动任务。

## 启动和清空机载任务

集群启动任务前先回读所有绑定成员的机载航线。所有剩余成员通过校验后才发送第一条启动请求。
对于本任务先前规划上传的航线，还会比较已核验的内容快照。
同内容回读、当前航点标记变化以及 GLOBAL/RELATIVE 的 INT 表示不会被误判为替换航线；实际内容变化需要重新规划确认。

当前校验支持多旋翼的顺序航点、普通起飞、普通降落以及能够解析的直接返航。
高度支持 GLOBAL 和 GLOBAL_RELATIVE_ALT，包括对应的 INT 帧。起飞须在首项，降落和返航须在末项。
跳转、地形高度、非连续执行、绕行参数、未知命令或缺少必要 Home/位置/高度时，集群启动会被拒绝。
这类任务可以转到标准 QGC 工作流处理；集群入口没有跳过检查的按钮。

校验包含航线线段、转场、允许区边界、禁飞区、限高，以及基于既有模型的通信距离和电量估算。
允许区边界可用，禁飞区边界不可用。电量估算仍是模型估算，不构成真实续航保证。
PX4 直接返航要求可解析的 Home、RTL 参数及空的安全点列表；ArduCopter 还检查相对高度和最终降落设置。
固件参数通过 FirmwarePlugin 和 Fact 读取。PX4 路径依据仓库中配套的 Navigator 源码；
ArduCopter 参数兼容性参照其[返航实现](https://github.com/ArduPilot/ardupilot/blob/master/ArduCopter/mode_rtl.cpp)。
返航高度采用保守上界，可能拒绝实际飞行高度更低的锥形返航。

清空任务是异步事务。整批预检中任一任务管理器忙碌时拒绝请求，避免打断另一个上传。
受理后先等飞控清空确认，再回读验证没有任务项。清空确认期限为 15 秒，回读期限为 120 秒。
接口“受理”不等于“清空成功”；以逐机 verified 状态和最终执行结果为准。
断开连接、拒绝、超时和不一致都会报告失败；退出的成员不再参与该批次的成功判定。

## 成员退出和任务结果

对选中成员暂停、返航或降落，只使这些成员退出当前多阶段任务和编队。
剩余成员继续后续阶段，领机退出时由剩余成员接替。退出成员不会自动重新加入。
整项任务中止会取消并暂停所有仍归该任务控制的成员。

每次启动产生唯一 taskId。任务结果区分 None（尚无终态）、Succeeded、Aborted 和 Failed。
终态快照包含原因、完成成员、退出成员和逐阶段动作派发记录。
清理和持久化在终态通知之前完成，通知接收者可启动新任务。
磁盘保存错误独立显示，不会把已经完成的飞行任务改写为成功或失败的其他结果。

验收工具绑定 taskId 判定结果。场景 09 在清理前验证剩余成员执行了任务内返航并已上锁，
且退出成员没有收到后续任务动作。清理成功不能覆盖此前失败。

## 配置同步

配置文件位于应用数据目录的 `SwarmConfig/fences.json`。
指令检查、态势地图和告警共享同一个配置版本。文件及其父目录均被监听，因此编辑器原子替换文件也能触发刷新。
下发前会同步检查文件内容；500 毫秒刷新节拍在感知接收停止时仍运行。

文件损坏、删除或数值非法时，起飞、航线启动和编队等相关动作受限。
地图保留上次有效围栏，面板显示配置无效提示，避免把读取失败显示成没有围栏。
恢复配置后需要操作员重新处理被拒绝或已取消的任务。暂停、返航和降落等人工恢复控制仍可使用。

## 感知容量

| 对象 | 上限或清理规则 |
| --- | --- |
| 融合航迹，含 tentative | 1024 |
| 全局来源记录 | 8192 |
| 每条融合航迹的贡献来源 | 最多 64 个，保留最近 10 秒 |
| 等待融合的报告 | 8192，满载时丢弃最早排队报告 |
| 每轮融合处理 | 最多 128 条或约 2 毫秒，然后交还事件循环 |
| 告警冷却记录 | 8192，过期或对象消失时清理 |
| 速度历史 | 随活跃航迹清理 |

已知来源更新优先保留，容量不足时拒绝新增状态，并记录诊断计数。
容量告警最多每 30 秒报告一次。经纬度在入口和热力图模型中均检查有限值和合法范围；有效的 `(0,0)` 可进入感知模型。
聚集检测用空间索引筛选候选，最终仍按原球面距离判定。

传输契约见[感知协议 v2](PERCEPTION_PROTOCOL_V2.md)。容量限制不会替代真实负载、硬件和长时间运行测试。
本轮实测范围与未完成的环境验收应以对应测试报告为准。
