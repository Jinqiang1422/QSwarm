# 集成补丁说明

本文档给出把 `src/Swarm/` 扩展代码集成进 QGroundControl 源码树所需的全部改动。
目标基线：**QGroundControl master（v5.x，Qt6 + CMake，单例管理器架构）**。

改动共 6 处，全部为追加式修改，不删除任何现有代码。

---

## 补丁 1：拷贝扩展源码

```
QGC集群扩展代码/src/Swarm/          →  qgroundcontrol/src/Swarm/
    ├── CMakeLists.txt
    ├── SwarmAction.h               （统一动作结构）
    ├── SwarmManager.h / .cc
    ├── FormationController.h / .cc
    ├── SwarmMissionPlanner.h / .cc
    ├── SwarmAIAgent.h / .cc        （大模型任务接口，Function Calling）
    ├── SwarmTaskController.h / .cc （任务状态机）
    └── SwarmTaskLibrary.h / .cc    （任务模板库）

QGC集群扩展代码/src/FlyView/
    ├── SwarmControlPanel.qml       →  qgroundcontrol/src/FlyView/SwarmControlPanel.qml
    └── SwarmAIPanel.qml            →  qgroundcontrol/src/FlyView/SwarmAIPanel.qml
```

> 说明：SwarmAIAgent / SwarmTaskController / SwarmTaskLibrary 都作为 SwarmManager 的子对象暴露
> （`QGroundControl.swarmManager.aiAgent` / `.taskController` / `.taskLibrary`），
> 因此**不需要**在 QGCApplication / QGroundControlQmlGlobal 上新增任何补丁，
> 只需使用本仓库中的 SwarmManager.h/.cc 与 CMakeLists.txt。
> 仓库 `templates/` 目录仅为内置模板的参考副本，运行时由 SwarmTaskLibrary 自动落盘到用户目录，无需手工拷贝。

## 补丁 2：`src/CMakeLists.txt` —— 注册 Swarm 子目录

在 `add_subdirectory(FollowMe)` 附近插入一行：

```cmake
add_subdirectory(FlyView)
add_subdirectory(FlightMap)
add_subdirectory(FollowMe)
add_subdirectory(Swarm)          # 新增：集群指挥控制模块
```

> Swarm 模块与 FollowMe 一样是纯 C++ 模块，源码直接编入主程序目标，
> 无需在 `target_link_libraries` 中新增库。

## 补丁 3：`src/QGCApplication.cc` —— 初始化单例

文件头包含区追加：


在 `MultiVehicleManager::instance()->init();`（约第 278 行）之后追加：

```cpp
    MultiVehicleManager::instance()->init();
    SwarmManager::instance()->init();          // 新增：集群指挥控制初始化
```

## 补丁 4：`src/QmlControls/QGroundControlQmlGlobal.h` —— 暴露给 QML

类声明中追加（与 `multiVehicleManager` 属性同一区域）：

```cpp
    Q_PROPERTY(SwarmManager* swarmManager READ swarmManager CONSTANT)
```

公有方法区追加：

```cpp
    SwarmManager* swarmManager() { return _swarmManager; }
```

私有成员区追加：

```cpp
    SwarmManager* _swarmManager = nullptr;
```

文件头部前向声明区追加：

```cpp
class SwarmManager;
```

> QGroundControlQmlGlobal 对 Q_PROPERTY 使用的自定义类型需保证 MOC 可见，
> 参照该文件现有 `MultiVehicleManager` 的 `Q_MOC_INCLUDE` 写法追加：
> ```cpp
> Q_MOC_INCLUDE("SwarmManager.h")
> ```

## 补丁 6：Fly View 界面集成

### 6a. `src/FlyView/CMakeLists.txt` —— 登记 QML 文件

在 `qt_add_qml_module(FlyViewModule ... QML_FILES ...)` 列表中（按字母序放在 `TelemetryValuesBar.qml` 附近）追加：

```cmake
        SwarmAIPanel.qml
        SwarmControlPanel.qml
```

### 6b. `src/FlyView/FlyViewWidgetLayer.qml` —— 实例化面板

在 `FlyViewWidgetLayer` 根 `Item` 内（例如 `FlyViewTopRightPanel` 声明之后）追加：

```qml
    // 集群指挥控制面板：停靠在左侧工具条下方，可折叠
    SwarmControlPanel {
        id:                     swarmControlPanel
        anchors.left:           parent.left
        anchors.leftMargin:     _toolsMargin
        anchors.top:            toolStrip.bottom
        anchors.topMargin:      _toolsMargin
        maxHeight:              parent.height - toolStrip.height - (_toolsMargin * 4)
        z:                      QGroundControl.zOrderWidgets
        visible:                QGroundControl.multiVehicleManager.vehicles.count > 0
    }

    // AI 集群指挥面板：停靠在集群面板下方，可折叠
    SwarmAIPanel {
        anchors.left:           parent.left
        anchors.leftMargin:     _toolsMargin
        anchors.top:            swarmControlPanel.bottom
        anchors.topMargin:      _toolsMargin
        maxHeight:              parent.height - toolStrip.height - swarmControlPanel.height - (_toolsMargin * 6)
        z:                      QGroundControl.zOrderWidgets
        visible:                QGroundControl.multiVehicleManager.vehicles.count > 0
    }
```

> `toolStrip` 与 `_toolsMargin` 均为 FlyViewWidgetLayer.qml 中已有对象/属性，直接可用。
> 位置可按需调整（例如改挂右侧 `topRightPanel.bottom`）。

## P3 追加补丁点（感知融合与态势理解）

### 补丁 5：FlyView 地图态势叠加层（WP3.4 COP）

文件：`src/FlightDisplay/FlyViewWidgetLayer.qml`（与补丁 4 同文件）

在地图组件（`FlightDisplayViewMap` 或其内层 `Map`）内追加子项：

```qml
// 集群态势叠加层：目标航迹/威胁区/覆盖热力（数据来自 SwarmManager.copModel）
SwarmSituationLayer {
    map:          flightMap           // ← 替换为实际 Map 组件 id
    swarmManager: QGroundControl.corePlugin.swarmManager   // ← 与面板同一实例来源
    showHeatmap:  true
    showThreats:  true
    showTracks:   true
}
```

> `SwarmSituationLayer.qml` 位于 `src/FlyView/`，随 QGroundControl QML 模块注册。
> 若 FlyView 地图无直接子项挂载点，可改在 `FlightDisplayViewMap` 的 `mapItems` 容器内添加。

### 补丁 6：QGCApplication 初始化（无改动则跳过）

`SwarmManager::instance()->init()` 已在 P0 补丁中接入；P3 起 `init()` 会默认启动
感知链路 UDP 监听（端口 15600，`Swarm/perceptionAutoStart` 可关、
`Swarm/perceptionPort` 可改），无需新增初始化代码。

### 感知服务部署（独立进程，不侵入 QGC 构建）

```bash
# 地面 GPU 工作站
pip install ultralytics numpy scipy
python3 services/perception/service.py --scenario real_feed.json \
    --out udp://<QGC主机IP>:15600 --realtime
```

## 编译

```bash
cd qgroundcontrol
cmake --preset default            # 或沿用你现有的 Qt6 构建配置
cmake --build build/default -j$(nproc)
```

编译完成后运行 QGroundControl，接入任意 PX4 SITL 实例（单机即可先验证面板加载），
多机接入后面板左上角计数随之增加，即可进行集群操作。
验证流程见《QGC集群指挥控制二次开发方案.md》第 8 章。
