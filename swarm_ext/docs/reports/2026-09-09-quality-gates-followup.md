## 全库门禁与范围

全量格式诊断检查 1701 个文件，1197 个既有文件与当前 clang-format 规则不一致。曾在隔离工作树整理格式并完成构建，
随后撤回与本轮缺陷无关的批量修改；只保留所修改文件的格式整理。
探索补丁和诊断日志仍在证据目录，未作为源码提交。

完整 pre-commit 工具安装曾遇到网络中断，以及 Node `lts` 别名解析到 22.19 后不满足依赖的情况。
两个 Node 钩子的版本已固定；任务专用 Go 工具链升级至 1.25.7；下载缓存保留供后续复用。Python 3.12 的两个本地安装 wheel 按 `tools/uv.lock` 哈希核验，
其余测试依赖沿用锁定版本。未降低 lint 规则或以跳过检查冒充通过。其余文件中仍有 74 处生产断言命中，需按执行路径进一步审查；
断言命中数量不等同于已确认缺陷数量。详见 `cpp-format-full-final.json` 和 `production-assertions-baseline.log`。

完整检查结束后，隔离工作树中由钩子自动调整的文件均未带回主工作区；31 个本轮源码文件的哈希没有被钩子改变。
钩子状态统计需要结合实际输出解释：

- 格式、行尾、可执行标记、CMake、YAML、Markdown 和拼写检查存在既有不合规项；Ruff 格式检查另报 48 个既有 Python 文件。
- 全局 Pyright 报 53 错误、59 警告，含缺少项目测试依赖的环境问题；对本轮五个 Python 文件显式指定已核验的 Python 3.12 环境后为 0 错误、0 警告。
- 固定等待钩子命中 `BluetoothLiveAdapterTest.cc` 注释中的旧调用字样，属于注释误报；本轮修改文件中没有固定等待调用。
- 宿主机 qmllint 为旧版 1.0，不支持当前入口的 `--bare`；隔离副本缺少编译数据库，Clang-Tidy 未执行，Clazy 包装器虽返回成功但实际跳过。因此不能据此声明 C++ 静态分析通过。
- Hadolint 因现有文件匹配规则没有匹配目标而跳过。Vale 同步到了全局样式目录，但配置要求的项目样式目录不存在，导致后续检查失败。
- TruffleHog、Renovate 配置校验、Actions 语法检查等钩子执行通过；不等同于完整历史密钥审计或所有安全风险已排除。

上述剩余项应作为仓库门禁基线治理处理。详细失败位置、工具输出和环境核验均在本轮证据目录，
本轮不将全库 lint 标记为通过，也不将检查器误报或环境缺项直接计为软件功能缺陷。

本轮没有改变此前 QA 修复的实飞验证边界。未重跑全部 SITL 场景，未覆盖真实飞行器、多操作系统和长期运行。
