## 修复内容

| 范围 | 已确认的问题 | 修复行为 |
| --- | --- | --- |
| 离线参数 | 读取数值后未赋给 Fact；存储使用组件占位 ID，查询使用实际组件 ID | 使用实际组件 ID 保存 Fact，并设置文件中的原始值；检查行格式、组件、名称、类型、数值范围与重复项；文件打不开立即返回 |
| 模拟参数协议 | 错误目标、未知参数、非法索引可能触发断言、越界访问或隐式插入 | 验证请求后处理，支持指定组件的参数列表；按参数 ID 字段的 16 字节上限复制；参数流完成检查也在互斥锁内执行 |
| MAVLink 通道 | 第三个通道分配失败后，已释放的通道 ID 未复位，重复清理可能释放其他使用者的资源 | 独立释放并复位每个通道，分配失败走统一回收路径，重复分配返回失败 |
| 模拟日志下载 | seek/read 放在断言中，关闭断言时不会执行；偏移加长度可能溢出 | 实际执行并检查文件操作，用文件大小减偏移后限制长度，读取失败停止发送，避免返回错误数据 |
| 模拟 FTP | 短读后仍按请求长度复制，可能越界读取；未打开文件时仍接受会话 | 直接读取到响应缓冲区并核验读取长度；失败返回 NAK；检查会话和目标组件 |
| 模拟任务协议 | 无效序号通过容器下标插入伪造航点；错误目标、未知任务类型和超时依赖断言 | 无效请求返回错误或忽略，读取不修改任务表或上传类型；错误应答携带请求自身的类型；复位清除任务、围栏、集结点和上传状态；实现未完成的主动发送测试接口 |
| 固件烧写 | 空镜像、未加载镜像和不符合协议长度的二进制缺少入口检查；校验失败仍调用重启 | 在串口操作前拒绝无效镜像及非 4 字节对齐的二进制；协议常量改为编译期检查；校验失败不重启 |
| 地图初始化 | 缺失、已销毁或线程不匹配的 QML 引擎依赖断言；可空错误输出被直接解引用 | 跟踪引擎生命周期，失败返回明确错误；错误输出指针可空，缺失网络管理器时提前结束 |
| 视频、摇杆和模型 | 线程约束或内部状态依赖运行时断言，部分断言与已有检查重复 | 保留必要的线程与指针检查，错误时返回；删除已有防护覆盖的重复断言，固定正则表达式不再依赖断言 |

旧门禁的 73 处匹配包含 `src/` 中 71 处断言及编码示例中的 2 行注释，不等于 73 个独立 bug。
最终上述匹配均已清零，未降低门禁阈值。
