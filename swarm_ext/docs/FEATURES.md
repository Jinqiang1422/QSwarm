# QGC 集群扩展功能与验证边界

更新：2026-09-07，开发工作树基于 `3de0014f7`。历史方案描述不作为当前验收结论。

| 功能域 | 当前实现 | 验证与边界 |
| --- | --- | --- |
| 多机指挥 | 批量解锁、起飞、暂停、返航、降落、任务启动；动作固定目标机号，排队后复检租约 | 使用选中集或解析时全体快照；指定目标无效时拒绝整计划 |
| AI 指挥 | 18 个工具、Function Calling/JSON、候选方案、参数编辑、监督确认 | L1 禁止自动执行；L2/L3 强制确认独立于可选“所有动作均确认”；来源名称不能代替授权 |
| 约束与覆盖 | 统一覆盖中心、区域包含/相交、转场/返航检查、覆盖高度、航程电量与链路估算 | 硬错误阻断确认和执行；允许区采用同一多边形完整包含的保守判据；不支持跨日期变更线围栏 |
| 编队与分配 | 4 种队形；sequential/auction/CBBA；固定编队目标集 | 分配在 QGC 侧计算，尚不代表机载分布式部署；去冲突仍有启发式和动力学验证边界 |
| 多阶段任务 | 9 套模板、人工门控、超时中止、约束阻塞、重试当前阶段 | 阻塞态不计时推进；人工重试重新检查，不跳过失败阶段 |
| 持久化 | 原子任务元信息快照，重启提示未完成任务 | 未保存完整航点与阶段进度；必须重新规划/启动，不自动续飞 |
| 感知与态势 | UDP/TUNNEL、检测跟踪、航迹融合、COP 图层、告警与摘要 | 已有模拟链和 GUI 历史证据；真实视频输入已接线，硬件/模型指标需独立实测 |
| 视频输入 | 按 video_source 读取真实 BGR 帧；有限重连、读取失败报错、资源释放 | 使用配置中的固定标定位姿；移动机载相机仍需逐帧同步遥测/姿态。缓冲设置依赖解码后端 |
| 凭据 | 模型 API Key 仅本次进程会话有效，删除历史明文 QSettings 键 | 地址和模型名仍可持久化；未引入系统密钥环依赖 |
| 工程验证 | 独立模块、Python、QGC 真实调用链、QML、SITL、重复资格、Release 接口剔除 | 以实际报告中的提交/工作树状态为准；dry-run 不等于在线模型或真实飞行通过 |
