# QGC 集群扩展功能与验证边界

更新：2026-09-07，功能依据提交 e3226eccb。历史方案描述不作为当前验收结论。

| 功能域 | 当前实现 | 验证与边界 |
| --- | --- | --- |
| 多机指挥 | 批量解锁、起飞、暂停、返航、降落、任务启动；动作固定目标机号，排队后复检租约 | 使用选中集或解析时全体快照；指定目标无效时拒绝整计划 |
| AI 指挥 | 18 个工具、Function Calling/JSON、候选方案、参数编辑、监督确认 | L1 禁止自动执行；L2/L3 强制确认独立于可选“所有动作均确认”；来源名称不能代替授权；交付构建（`QGC_SWARM_AI_AUTODISPATCH=OFF`）不提供免确认自动下发，模型产物一律经人工确认，纯人工/纯大模型/人工+大模型三种编排模式均可用 |
| 约束与覆盖 | 统一覆盖中心、区域包含/相交、转场/返航检查、覆盖高度、航程电量与链路估算 | 硬错误阻断确认和执行；允许区采用同一多边形完整包含的保守判据；不支持跨日期变更线围栏 |
| 编队与分配 | 4 种队形；sequential/auction/CBBA；固定编队目标集 | 分配在 QGC 侧计算；停止编队只停止更新，不自动悬停；去冲突与动力学尚有验证边界 |
| 多阶段任务 | 9 套模板资产、人工门控、超时中止、约束阻塞、重试当前阶段 | 阻塞态不推进；接力模板空选机与严格解析冲突，暂不可直接运行；阶段完成不等于成果验收 |
| 持久化 | 原子任务元信息快照，重启提示未完成任务 | 未保存完整航点与阶段进度；必须重新规划/启动，不自动续飞 |
| 感知与态势 | UDP/TUNNEL、检测跟踪、航迹融合、COP 图层、告警与摘要 | 热力仅累计机体位置，不计算有效搜索覆盖；真实视频已接线，硬件/模型指标需独立实测 |
| 视频输入 | 按 video_source 读取真实 BGR 帧；有限重连、读取失败报错、资源释放 | 使用配置中的固定标定位姿；移动机载相机仍需逐帧同步遥测/姿态。缓冲设置依赖解码后端 |
| 凭据 | 模型 API Key 仅本次进程会话有效，删除历史明文 QSettings 键 | 地址和模型名仍可持久化；未引入系统密钥环依赖 |
| 工程验证 | 独立模块、Python、QGC 真实调用链、QML、SITL、重复资格、Release 接口剔除 | 以实际报告中的提交/工作树状态为准；dry-run 不等于在线模型或真实飞行通过 |

工具与模板以 `swarm_ext/tests/llm_eval/tools_schema.json`、`swarm_ext/templates/` 为准。`plan_tactic` 提供规划建议，不能视为对应战术已完成自动飞行闭环。

最近一轮验证：[SITL 验证与人工/模型任务等价性](reports/2026-09-24-sitl-verification.md)；交付边界与明确未覆盖项见[交付收尾验证记录](reports/2026-09-16-delivery-closure.md)第七节。测试入口：[测试说明](../tests/README.md)。运行方式：[用户使用手册](用户使用手册.md)、[感知服务](../services/perception/README.md)。

本次手册编写对按钮行为、模板和状态语义做了额外静态核对，详见 [功能分析与手册核验](功能分析与手册核验.md)。
