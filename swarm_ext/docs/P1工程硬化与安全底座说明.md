## 二、WP1.3 自主分级（行为矩阵）

| 等级 | AI 侧执行 | 说明 |
|---|---|---|
| L1 仅建议 | **一律禁止** | 计划生成后仅展示；confirmPlan 拒绝并提示；操作员手动直控不受限 |
| L2 监督执行（默认） | 含危险动作 → 挂起确认 | 现状行为归位；纯安全动作直接执行 |
| L3 限定域自主 | 白名单内危险动作**免确认自动执行**（仍过统一校验闸门 + 全程审计） | 白名单面板可裁剪；`emergency_disarm` 永不自动（只能人工显式触发） |

- 等级判定收敛于 `SwarmAutonomy::needsConfirmation()`（纯函数，QtCore-only，独立可测）。
- 持久化：`QSettings Swarm/autonomyLevel`、`Swarm/l3AllowedTypes`。
- 面板：等级下拉 + 行为说明 + L3 白名单复选组（仅 L3 可见）。

## 三、WP1.1 审计追溯

- 每会话一个 JSONL 文件：`AppDataLocation/SwarmAudit/session_<时间戳>_<随机>.jsonl`。
- 事件字段：`seq / ts_wall(UTC ISO ms) / ts_mono_ms(单调时钟) / session / category / action / data`。
- category 固定四类，覆盖"指令→推理→校验→下发→反馈"全链：

| category | action | 来源 |
|---|---|---|
| dialog | user_input / llm_request / llm_output | AIAgent（含过滤判定结果） |
| safety | validation / plan_pending / plan_confirmed / plan_rejected / autonomy_change | 校验闸门 |
| exec | action_sequence / action_dispatch / operator_command | SwarmManager（origin 归因：ai/ai_confirmed/task/template/operator） |
| task | task_started / stage_entered / stage_completed / stage_timeout / task_finished / task_failed / task_aborted / template_run | 状态机/模板库 |

- 导出：面板"导出当前会话"按钮 → `SwarmAudit/exports/`。
- 面板显示会话 ID 与已记录事件数。

## 四、WP1.2 防注入过滤

- 22 条中英注入模式（忽略先前指令/角色劫持/套取提示词/越狱/绕过安全等），权重计分：≥5 拦截（blocked）、≥2 可疑（suspicious）。
- 清洗：零宽字符剔除、重复串压缩、2000 字符截断。
- 接入点：AIAgent.sendText —— blocked 拒发、 suspicious 告警并审计后继续；操作员输入同样留痕。
- 内置 9 组攻击样例（`builtinAttackSamples()`），单元测试与 CI 遍历。
- P3 外部数据（目标上报文本等）进入 LLM 前复用同一过滤层。

## 五、WP1.4 评测集 v1（514 条）

类别分布：A 单动作 119 / B 多动作 17 / C 多阶段任务 8 / D 模板引用 14 / E 中止与问答 26 / F 越界拒绝 32 / G 歧义追问 17 / H 表达变体 278。

- **单源事实**：tools Schema 由 `export_tools.py` 从 SwarmAIAgent.cc 自动提取（16 工具），杜绝评测与实现漂移。
- 判定语义约定：解锁→`arm(true)`、上锁→`disarm`、紧急/强制→`emergency_disarm`、越界→拒绝且无工具调用、缺信息→追问。
- 指标：intent_accuracy（目标 ≥95%）、tool_name_accuracy、schema_valid_rate、refusal/clarify_accuracy。
- 基线首测需在目标环境执行：`python3 run_eval.py --api-key <KEY> --out report.json`。
